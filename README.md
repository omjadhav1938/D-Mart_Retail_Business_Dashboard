# 🛒 D-Mart Retail Business Dashboard

### 📊 Retail Sales • Profitability • Customer Insights

---

## 📌 Project Overview

The **D-Mart Retail Business Dashboard** is a Microsoft Excel project designed to analyze retail sales, profitability, customer behavior, discounts, and product categories.

The project uses an order-level dataset containing **15,345 records** to explore business performance across regions, cities, categories, payment methods, and customer types.

## 🎯 Project Objectives

- 📈 Analyze overall sales and revenue performance.
- 💰 Compare profit across different regions.
- 🛍️ Evaluate sales across product categories.
- 👥 Understand customer-type sales distribution.
- 🏙️ Compare sales performance across cities.
- 💳 Examine payment methods across regions.
- 🏷️ Explore discounts and quantities sold.
- 📅 Analyze sales trends by month and year.

## 📊 Dashboard Analysis

| Analysis | Business Focus |
|---|---|
| 💵 Sales Analysis | Total sales and regional performance |
| 💰 Profit Analysis | Profit comparison across regions |
| 🛍️ Category Analysis | Sales and quantity by product category |
| 🏙️ City Analysis | Sales comparison across cities |
| 👥 Customer Analysis | Member, new, and regular customer sales |
| 💳 Payment Analysis | Card, cash, and UPI transactions |
| 🏷️ Discount Analysis | Discount distribution across regions |
| 📅 Time Analysis | Monthly and yearly sales trends |

## 🛠️ Tools & Techniques

- **Microsoft Excel**

- Excel formulas and calculations
- Sales and profit analysis

## 📂 Dataset Details

The workbook includes fields such as:

- Order ID
- Region and City
- Product Category
- Sales and Profit
- Discount and Discount Value
- Quantity
- Order Date and Delivery Date
- Customer Type
- Payment Mode
- Net Revenue

## 🚀 How to Use

1. Download `D-Mart_Retail_Business_Dashboard.xlsx`.
2. Open the workbook in Microsoft Excel.
3. Start with the **D-Mart Retail Business Dashboard** sheet.
4. Explore the supporting worksheets for detailed sales, profit, customer, and category analysis.
5. Use available dashboard filters and interactive elements to explore the data.

## ⚠️ Disclaimer

This project is intended for educational purposes and Excel analytics practice. The dataset should not be considered official D-Mart company data.
